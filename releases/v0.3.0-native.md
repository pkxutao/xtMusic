# XT Music Native v0.3.0

XT Music 0.3.0 是第一个真正原生的 Rust 桌面版本。

## 架构

- `eframe/egui` GPU 原生界面
- `rodio` 系统音频输出
- `reqwest + rustls` 飞牛协议与安全网络层
- 不包含 Electron、Chromium、Node.js、Tauri、Wry 或 WebView

## 功能

- FN ID、`fnos.net` 完整地址和局域网地址登录
- 飞牛音乐应用内账号密码登录
- 访问安全码、自签名证书和 HTTP 局域网兼容选项
- 首页、歌曲、专辑、歌手、收藏和历史
- 大型歌曲列表行虚拟化
- 原生播放队列、上一首、下一首、暂停、进度和音量
- LRC 解析、同步歌词和点击歌词跳转
- Windows 与 Ubuntu 原生安装包

## 凭据安全

- 原始密码不会写入磁盘
- music-token 和访问安全码只保存在当前进程内存中
- 退出程序后会话自动清除
- 跨域重定向会删除 Cookie 和访问安全码
- 仅官方 `fnos.net` 与 `5ddd.com` HTTPS 中继之间保留必要的中继凭据

## 当前边界

首次播放会先把歌曲安全缓存到本地再交给系统解码器，因此超大无损文件的首次开始播放时间取决于网络速度；后续播放会直接使用缓存。DSF/DFF/SACD 服务端转码将在后续原生版本继续完善。
