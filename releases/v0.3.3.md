# XT Music v0.3.3 — Windows 登录后卡死修复

此版本针对 v0.3.2 中“登录成功后首页卡住、窗口响应迟缓”的回归问题。

## 修复

- 首页和上次访问页面优先加载，不再等待最多 5000 个歌单全部返回。
- 歌单改为后台、限量加载；侧边栏最多同步渲染 120 行。
- 播放队列关闭时不再生成任何隐藏 DOM。
- 长队列打开时只渲染当前播放项附近最多 160 行。
- 启动恢复的队列快照从 2000 首降至 500 首，并围绕当前曲目保存。
- 播放进度更新只刷新时间和进度条，不再反复重建封面和全部控制按钮。
- 封面恢复稳定的 `xtmusic://` 地址，重新获得跨启动磁盘缓存；随机本机 HTTP 代理只用于音频和 HLS。
- 图片使用延迟加载、异步解码和低请求优先级。

## 新增回归验证

Windows Electron 会模拟：

- 歌单接口延迟 3 秒；
- 5000 个歌单；
- 2000 首播放队列；
- 登录后首页必须先于歌单接口显示；
- 关闭队列必须为 0 个隐藏行；
- 打开队列最多 160 行；
- 压力后仍可立即切回首页。
