# XT Music v0.2.5

本版本重点修复 Ubuntu 升级与飞牛音乐账号登录问题。

## 主要修复

- 修复 Ubuntu 安装新版后，旧版托盘进程仍驻留，导致界面继续显示旧版本、旧代码继续运行的问题。
- DEB 升级前会安全停止 XT Music 的旧安装进程及旧 AppImage 进程，不删除用户配置、账号信息或音乐数据。
- 增加版本感知的单实例切换逻辑，后续升级时能够启动真正的新版本。
- Ubuntu 窗口标题和托盘提示显示真实运行版本，便于确认当前程序来源。
- 修复 `https://<FN-ID>.fnos.net`、`https://<FN-ID>.fnos.net/music/` 与纯 FN ID 的音乐服务连接流程。
- 修复 FNOS 与 5ddd 官方中继之间跳转时 `mode=relay` 丢失，导致飞牛音乐应用内账号登录失败的问题。
- 显式 HTTP/HTTPS 地址不再被错误转换成 FN ID，也不会被探测重定向地址覆盖。

## 安装建议

Ubuntu 推荐下载 `.deb` 文件并执行：

```bash
sudo apt install ./XT-Music-0.2.5-ubuntu-amd64.deb
```

安装后可通过以下命令确认版本：

```bash
dpkg-query -W -f='${Package} ${Version}\n' xtmusic
```

Windows 可选择安装版或 Portable 便携版。

## 安全说明

- 原始飞牛音乐密码不会持久化保存。
- 会话令牌仅在系统安全存储可用时加密保存。
- Release 附带 `SHA256SUMS.txt` 和 `BUILD-INFO.txt`，用于校验安装包和构建提交。
