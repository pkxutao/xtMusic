# XT Music v0.3.1 — Windows 界面回归修复

此版本修复 `v0.3.0` Windows 安装包发布了错误 UI 实现的问题。

## 修复内容

- 恢复经过验证的完整桌面音乐界面，不再使用尚未完成的 egui 重绘界面。
- 恢复标题栏、侧边栏、内容卡片、歌曲表格、播放队列、底部播放器和登录页的完整样式。
- 构建时强制检查 HTML 中引用的 CSS、JavaScript 与静态资源是否全部存在。
- 强制使用相对资源路径，避免安装到 Windows 后通过本地文件协议启动时样式丢失。
- Windows CI 生成 1440×900 安装态视觉快照，并检查主题变量、侧边栏宽度、标题栏和播放器高度。

## 安装说明

请先卸载或退出 `XT Music Native 0.3.0`，再安装：

```text
XT-Music-0.3.1-x64.exe
```

两个版本使用不同的应用标识，因此旧的 `XT Music Native` 可能仍保留在开始菜单中，可单独卸载。

## 技术说明

这是一个优先恢复可用性的 Windows UI 热修复版本。`v0.3.0` 的纯 egui 重绘版不再作为正式桌面界面的基础；后续 Tauri 迁移必须复用并通过同一套视觉快照后才会发布。
