# XT Music Native v0.3.0

XT Music 0.3.0 是首个完全原生桌面版本。

## 架构变化

- 删除运行时对 Electron、Chromium、Node.js 和 WebView 的依赖。
- 使用 Rust + egui/eframe 绘制所有桌面界面。
- 使用 rodio/cpal 连接系统原生音频输出。
- 飞牛协议、FN Connect、账号会话、媒体下载和缓存全部由 Rust 执行。

## 功能

- 支持 FN ID、`fnos.net`、内网 IP 和自定义域名。
- 支持飞牛音乐应用内账号、访问安全码和官方中继。
- 支持歌曲、专辑、歌手、风格、收藏、历史、歌单及搜索。
- 支持原生播放队列、音量、进度、循环、随机和同步歌词。
- 歌曲列表使用虚拟化渲染。

## 安全

- 原始密码永不持久化。
- Token 和访问安全码仅进入系统密钥环；不可用时只保留于内存。
- 非官方跨域重定向不会携带认证信息。
- 无遥测、广告、分析 SDK 或远程 UI。

## 安装包

- Windows x64 安装程序
- Ubuntu amd64 DEB
- Ubuntu x86_64 portable tar.gz
- SHA-256 校验文件

Electron `v0.2.5` 继续保留，便于回退。
