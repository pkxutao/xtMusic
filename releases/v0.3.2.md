# XT Music v0.3.2 — Windows 播放链路修复

此版本修复 Windows `v0.3.1` 中“界面正常，但点击歌曲后播放报错”的问题。

## 核心修复

- 不再让 HTML Audio 直接依赖 Electron 自定义协议承载音频流。
- 新增仅监听 `127.0.0.1` 的本机 HTTP 媒体代理，启动时生成 256 位随机路径密钥。
- 完整转发并校验 `Range`、`206 Partial Content`、`Content-Range`、`Content-Length` 与 MIME 类型。
- 封面、原始音频、HLS 清单、分片和加密密钥统一经过本机代理。
- HLS 清单中的相对地址、`EXT-X-MAP` 和 `URI` 属性全部重写为受保护的本机地址。
- 播放前用 2 字节 Range 请求验证音频流，避免只显示笼统的 Chromium 媒体错误码。
- 权限不足、会话失效、文件不存在、网络超时、格式不支持和转码失败会显示不同错误原因。
- 允许托盘和系统媒体键继续播放，避免 Chromium 自动播放策略误拦截桌面控制命令。

## 安全

- 媒体代理只绑定 IPv4 回环地址，不监听局域网网卡。
- 每次启动重新生成随机密钥，未持有密钥的本机请求返回 404。
- 飞牛 `music-token`、访问安全码和真实上游地址仍只保留在主进程。
- Renderer 只看到带随机密钥的 `127.0.0.1` 地址，不会获得飞牛凭据。
- 非官方跨域重定向继续移除 Cookie 和访问安全码。

## 验证

- 42 项协议、安全、歌词、升级和播放代理测试全部通过。
- Windows Electron 实际加载 WAV 媒体并验证 `loadedmetadata`、时长、MIME 与 Range。
- Windows UI 快照检查继续通过。
- NSIS 安装版和 Portable 版重新构建并生成 SHA-256。

请完全退出旧版托盘进程后安装 `XT-Music-0.3.2-x64.exe`。
