# 歌词播放体验

XT Music 的歌词页参考 Feishin 的交互原则重新设计，但不复制其 GPL 源码或素材。实现仍使用项目原有的原生 DOM、CSS 与播放器状态。

## 视觉层次

- 专辑封面、柔光、模糊封面背景和低强度动态环境光组成左侧视觉锚点。
- 歌词区域使用顶部/底部渐隐遮罩，当前歌词保持最大对比度，临近歌词按距离逐级降低透明度和比例。
- 当前行根据当前播放时间和下一行时间计算进度，以渐变文字表现轻量级的行级 Karaoke 效果。
- 页面进入、封面浮动、背景呼吸和歌词切换都遵循 `prefers-reduced-motion`。

## 自动跟随

应用原有的 `scrollIntoView` 只在歌词行范围内被安全拦截，并替换成居中的四次缓出动画。其他页面与第三方组件仍使用浏览器原生行为。

用户滚轮、触摸或拖动歌词区域后，自动跟随暂停 3.2 秒，并显示“回到当前歌词”。点击歌词跳转、点击跟随按钮或超时后会恢复跟随。

## 交互

- 点击歌词：跳转到该行时间。
- 双击封面：播放/暂停。
- `Esc`：返回上一页（模态框或右键菜单打开时不抢占）。
- 悬停歌词：显示对应时间。
- 小窗口：自动隐藏大封面，将歌词扩展为单列布局。

## LRC 兼容

解析器支持：

- 多时间标签
- 1～3 位小数时间戳
- `[offset:+/-ms]`
- UTF-8 BOM
- Enhanced LRC 单词时间标签的文本清理
- 空白同步行
