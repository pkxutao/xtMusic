# XT Music Android 0.1.0-alpha04 · 留声机播放页

## 本次更新

- 播放页改为原生黑胶唱片与唱针界面。歌曲封面位于唱片中央，正常播放时顺时针约 24 秒一圈；暂停后保留角度，继续播放时从原角度旋转。准备播放、离开页面、切换到歌词及进入后台时停止唱片动画，并尊重系统关闭动画的设置。
- 点击唱片或底部“词”进入独立歌词视图；点“碟”、页头返回或系统返回键回到唱片，再次返回退出播放页。两种视图共享播放控制与进度，不重新启动音频服务。
- 保留 XT Music 原有深色背景、紫色强调色、圆角按钮、粉色收藏按钮、歌手/专辑跳转和播放队列。横屏采用左右布局，小屏唱片自适应缩放。
- 保留同步歌词高亮、自动滚动与点击歌词跳转；手动浏览歌词后约 4 秒恢复自动跟随。补充无歌词、未连接和失败重试提示。
- 避免每次播放状态更新重复加载封面；离开页面释放封面加载器。防止切歌后的旧歌词/收藏异步结果覆盖当前歌曲。

## 构建与验证

构建从提交中的 Kotlin 源码直接进行，不在构建时重新生成或覆盖业务代码。

```sh
gradle -p android --no-daemon testDebugUnitTest lintDebug assembleDebug
gradle -p android --no-daemon connectedDebugAndroidTest
```

新增 JVM 测试覆盖动画启停条件、旋转角度归一化和唱片尺寸规则。Android 仪器测试覆盖旋转/暂停/继续、歌词切换、系统返回、后台暂停、页面重建、空播放状态、队列以及布局边界。模拟器截图由实际应用界面生成，使用测试包内的本地封面与原创歌词数据；这些测试数据不会进入正式应用，也不包含音乐库账号或令牌。

GitHub Actions 的测试报告、截图、APK 签名信息及 SHA-256 校验文件随构建保存。BUILD-INFO.txt 记录对应源代码提交和构建链接。

## 安装说明与验证边界

- Android 8.0 / API 26 及以上；通用 APK。应用版本 0.1.0-alpha04，versionCode 4。
- 延续此前 Android alpha 的 debug 安装包形式，包名为 `com.pkxutao.xtmusic.android.debug`；这是预发布测试版，不是使用生产签名密钥签名的正式发行包。
- CI 使用 Android debug 证书。不同构建的证书可能不同，旧包不能保证直接覆盖安装；出现签名冲突时请先保留必要信息，再卸载旧测试版并重新安装，卸载会清除本地账号配置与缓存。
- UI 测试使用隔离的模拟器和本地播放状态，不连接用户的私人 FNOS 音乐库，不代表已在用户手机上验证真实音频播放、音频焦点、通知栏或蓝牙设备。原有音频播放服务与协议代码未改动。
- 此版本为独立 Android prerelease，不替换已有桌面端 v0.3.7 Release 或其附件。
